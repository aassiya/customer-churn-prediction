# Предсказание оттока клиентов с использованием методов машинного обучения на основе деревьев

В проекте решается задача предсказания оттока клиентов телекоммуникационной компании с использованием методов машинного обучения на основе деревьев решений.

Проведен полный цикл работы с данными: исследовательский анализ (EDA), анализ распределения признаков, проверка пропусков, сегментация клиентов по времени использования сервиса (когортный анализ) и исследование факторов, связанных с оттоком пользователей.

Для решения задачи реализовано и сравнено несколько моделей машинного обучения: Decision Tree, Random Forest, AdaBoost и Gradient Boosting. Выполнен подбор гиперпараметров с использованием GridSearchCV, проведена оценка качества моделей на тестовой выборке и сравнительный анализ их эффективности.

**Стек:** Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn.
